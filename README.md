# Road Tracker

Сайт для учёта поездок на работу и обратно: время в пути, расходы в гривнах, этапы и пересадки, контролёры, история с календарём, аналитика и прогноз расходов. Устанавливается на iPhone как приложение («На экран Домой») и работает без интернета.

Нативная iOS-версия (этапы 1–2) сохранена в ветке [`ios-app`](../../tree/ios-app).

## Как пользоваться на iPhone

1. Откройте сайт в Safari.
2. «Поделиться» → «На экран Домой».
3. Запускайте с иконки: без адресной строки, работает офлайн.

Данные хранятся в браузере (IndexedDB). Чтобы они не пропали при очистке Safari и были на других устройствах — подключите облако (ниже).

## Что умеет

- **Главная — пульт**: на первом экране (даже iPhone SE) «Старт», «Обычная поездка» и расходы сегодня/за месяц. В центре меню — «Добавить», во время записи там же — «Поездка».
- **«Обычная поездка» в одно касание**: сайт сам берёт ваш частый маршрут, цену, время выезда и длительность; после записи есть «Отменить».
- **Команды iPhone** (Профиль → Автоматизация): ссылки-действия `#/do/start`, `#/do/toggle`, `#/do/finish`, `#/do/usual`, `#/do/add` и рецепты — старт при уходе из дома, NFC-метка у двери, запись обычных поездок по расписанию без дублей.
- **Бюджет месяца**: сколько осталось, сколько можно тратить в будний день и уложитесь ли вы при текущем темпе.
- **Поездка**: пауза, завершение; запись переживает перезагрузку и закрытие вкладки.
- **Этапы**: «Сел в транспорт» (маршрутка №720 → метро), стоимость, номер, время; пересадки считаются автоматически.
- **Контролёры** на каждом этапе (5 вариантов), статистика с размером выборки и 95 % интервалом — без выдачи случайностей за вероятность.
- **GPS**-трек и расстояние — всей поездки и каждого этапа, пока сайт открыт (экран не гаснет); подсказка «Вы на месте — завершить?» у Дома/Работы.
- **Шаги** на этапах «Пешком»: по датчику движения телефона (пока сайт открыт), иначе оценка по расстоянию GPS и длине шага от роста, а без GPS — по времени ходьбы (оценки со знаком «≈»). Итоги — в истории и аналитике.
- **Шаги из «Здоровья»** одной кнопкой — через команду iPhone «Road Tracker шаги» (рецепт на странице «Команды iPhone»).
- **Цвета транспорта**: у каждого вида свой цвет — иконки, точки этапов, линия маршрута на карте (по участкам), доли расходов.
- **Старт с выбором транспорта**: автобус, маршрутка, пешком (и другие) и цена; в пути — «Сменили транспорт?» в два касания, можно «2 мин назад».
- **Места** на карте (OpenStreetMap) и **шаблоны маршрутов** со стартом в одно касание.
- **История**: календарь месяца с итогами по дням, список, фильтры (дата, направление, транспорт, стоимость, контролёры, маршрут).
- **Аналитика**: до трёх выводов словами над графиками, расходы за неделю/месяц/год, по направлениям и транспорту, сравнение с теми же днями прошлого периода, прогноз, калькулятор «деньги против времени» по вашим реальным маршрутам (без выдуманных цифр).
- **Резервная копия** в «Файлы»/iCloud Drive через меню «Поделиться» и восстановление из неё; без облака главная раз в неделю напоминает сохранить копию.
- **Облако** Supabase: вход, оффлайн-очередь, синхронизация между устройствами, удаление аккаунта; экспорт в CSV.
- **Офлайн**: сайт открывается из кэша без сети (меньше секунды), карта — из собственной копии Leaflet, уже виденные места карты тоже доступны без сети. Новая версия скачивается в фоне — внизу появляется «Обновить».

Интерфейс и дизайн-система описаны в [docs/UI_REPORT.md](docs/UI_REPORT.md); превью компонентов — страница `#/design`.

## Ограничения браузера на iPhone (честно)

| Хотелось бы | Что возможно в Safari | Что сделано |
|---|---|---|
| GPS в фоне | Нет: сайт получает геолокацию только когда открыт | Экран не гаснет во время записи (Wake Lock); время поездки считается всегда |
| Автоопределение выхода из дома (геозоны) | Нет | Подсказка завершить поездку у известного места, пока сайт открыт |
| Ссылки из «Команд» в установленный сайт | Ссылка открывается в Safari, а у сайта на экране «Домой» отдельное хранилище | Подключите облако — тогда данные общие; или пользуйтесь сайтом в Safari |
| Уведомления | Только у установленного на экран «Домой» сайта, и только пока он работает | Подсказки внутри приложения |
| Надёжное хранение | Safari может удалить данные неиспользуемого сайта через ~7 дней | Запрос постоянного хранилища + облако + экспорт |

## Облако (Supabase, бесплатно)

1. Создайте проект на [supabase.com](https://supabase.com).
2. SQL Editor → выполните по порядку файлы из `supabase/migrations/`. Если облако уже подключено — выполните новый `20261104000003_segment_steps.sql` (шаги этапа); без него шаги по датчику останутся только на устройстве.
3. Project Settings → API: скопируйте **Project URL** и **anon / publishable key**.
4. В приложении: Профиль → Облако → вставьте адрес и ключ → Регистрация.

В браузер попадает только публичный anon key — он для этого предназначен; доступ к строкам ограничивает Row Level Security (каждый видит только свои данные, проверено тестами). Секретный service_role key никуда не вводите.

## Публикация (GitHub Pages)

Один раз: **Settings → Pages → Source: GitHub Actions**. После этого каждый push в `main` проходит тесты и публикует папку `app/` по адресу `https://<логин>.github.io/road-tracker-/`.

## Разработка

Без сборки и зависимостей: ES-модули, IndexedDB, Supabase REST.

```bash
cd app
python3 -m http.server 8080          # http://localhost:8080
node --test tests/*.test.js          # логика, хранилище, синхронизация
node tests/e2e/smoke.mjs             # сквозные проверки в headless Chrome
SHOTS_DIR=shots node tests/e2e/screens.mjs   # скриншоты экранов на 3 размерах iPhone
scripts/build-sw.sh                  # после любого изменения файлов — список и версия оффлайн-кэша (CI проверяет)
BROWSER=chromium node tests/e2e/webkit.mjs   # те же проверки, что в CI на WebKit (движок Safari)
../supabase/tests/run_local.sh       # схема БД и RLS на временном PostgreSQL
```

```
app/
  index.html, styles.css, sw.js, manifest.webmanifest, icons/
  vendor/     Leaflet 1.9.4 (кладётся workflow «Vendor» из npm, без CDN)
  src/core/   чистая логика: деньги, время/часовые пояса, GPS, аналитика, выводы, бюджет,
              «обычная поездка», резервная копия, контролёры, машина состояний поездки,
              политика синхронизации, проверка и фильтры
  src/data/   IndexedDB, хранилище (атомарные изменения + очередь), Supabase REST
  src/ui/     интерфейс: вкладки, редакторы, календарь, карта
  tests/      node-тесты и e2e в Chrome
supabase/     миграции и тесты схемы
docs/         аудит и план
```

# Road Tracker — отчёт по интерфейсу (premium UI/UX)

Дата: 4 ноября 2026. Проект — сайт для iPhone (PWA), поэтому требования ТЗ, написанные под SwiftUI, реализованы веб-аналогами:

| В ТЗ | Сделано |
|---|---|
| SwiftUI-компоненты + Preview | JS-компоненты (`app/src/ui/components.js`) + страница превью `#/design` |
| MapKit | Leaflet + OpenStreetMap (тёмная подложка), живая карта поездки без пересоздания |
| Swift Charts | Собственные SVG/CSS-графики: подписи осей, сетка, анимация роста, подсказка по нажатию, пустые состояния |
| SwiftData + Supabase | Без изменений: IndexedDB + Supabase REST |
| iOS Simulator | Headless Chrome на 375×667 (SE), 393×852 (15), 430×932 (15 Pro Max) |

## Визуальный язык
- Глубокий графит (`#0b0d10`), электрический зелёный акцент, тонкие разделители вместо множества карточек.
- Фирменный мотив — **дорожная разметка**: пунктирное кольцо вокруг кнопки старта (вращается при записи), «дорога» прогресса месяца, пунктирная линия этапов поездки и маршрута.
- Цифры — системный округлый шрифт (SF Pro Rounded на iPhone), табличные цифры.

## Дизайн-система (`app/styles.css`, раздел 1)
- **Цвета:** Background Primary/Secondary, Surface Primary/Elevated, Accent Green, Text Primary/Secondary/Tertiary, Success, Warning, Danger, Border. Светлая тема подготовлена токенами (`data-theme="light"`).
- **Типографика:** Display, Heading, Subheading, Body, Caption, Numeric (L/XL). Размеры в `rem` от `-apple-system-body` — следуют настройке «Размер текста» iPhone (аналог Dynamic Type).
- **Отступы:** токены `--s-1…--s-12`, шаг 4 px.
- **Компоненты:** PrimaryButton, SecondaryButton, Segmented, TransportSelector, MetricCard, TripCard, ExpenseCard, TrackingStatus, ChartContainer, EmptyState, BottomNavigation, Bottom Sheet / ConfirmationSheet, сгруппированные ячейки настроек, Skeleton.

## Экраны
1. **Главная** — логотип, приветствие по времени суток, дата, статус GPS; большая кнопка «Старт» с анимацией запуска и живым таймером во время записи; выбор направления; метрики дня (время, расходы, поездки и пересадки, средняя поездка); последняя поездка; прогресс месяца против прошлого месяца; быстрые действия (добавить, повторить последнюю, шаблоны).
2. **Активная поездка** — карта на ~половину экрана с живым маршрутом (без GPS — компактная заглушка и кнопка «Включить GPS»), таймер с секундами, расстояние, время старта, стоимость, текущий транспорт, линия этапов, «Сел в транспорт» и «Контролёр» в нижних шторках, пауза, завершение.
3. **Добавление поездки** — нижняя шторка: подстановка прошлой поездки в этом направлении (стандартная поездка — «Добавить» → «Сохранить»), Сегодня/Вчера, время, длительность чипами, автодополнение шаблонов и номеров маршрутов, иконки транспорта, крупное числовое поле и частые суммы из истории; «Подробнее» — полный редактор с тем же черновиком.
4. **История** — календарь месяца: заполненные дни, сегодня, яркость полосы = расходы, оранжевая точка = контролёр; выбор дня открывает шторку с итогами и поездками дня; список по дням; фильтры в шторке со счётчиком результатов.
5. **Аналитика** — период (неделя/месяц/год); расходы и время в дороге (интерактивные графики); транспорт (доли и суммы); сравнение реальных маршрутов из истории (среднее время, средняя цена, цена минуты); прогноз; контролёры (доля, 95 % интервал на шкале, уровень достоверности, проверки по часам); калькулятор экономии.
6. **Профиль и настройки** — аккаунт/облако и синхронизация; Дом, Работа, все места, шаблоны; подсказка «вы на месте» (геозоны); GPS по умолчанию и статус разрешения; уведомления с запросом разрешения; валюта; экспорт CSV и JSON; приватность (удаление истории геолокации, удаление аккаунта); инструкция по установке.

## Микровзаимодействия
Анимация запуска поездки, пульс/вращение разметки при записи, тиканье таймера, плавное появление секций, рост столбцов графиков, шторки снизу, переключатели в стиле iOS, скелет при загрузке, понятные экраны ошибок (хранилище, карта, синхронизация). Тактильный отклик: Android — Vibration API; iPhone (iOS 18+) — системный «тик» через переключатель. Все анимации отключаются при «Уменьшении движения».

## Доступность и адаптивность
Safe Areas (включая карту под вырезом), `100dvh`, подъём шторки над клавиатурой (`visualViewport`), подписи для экранного диктора (календарь, графики, статусы, кнопки-иконки), `aria-pressed`/`aria-current`, видимый фокус, контраст текста на графите, проверка на 375/393/430 pt.

## Исправленные проблемы (аудит)
- «−80 % к прошлому месяцу» в начале месяца → сравнение с теми же днями прошлого месяца.
- Прогноз занижался для новых пользователей (недели до первой поездки считались «днями без поездок») → считается с первой поездки.
- Графики без значений и подсказок → оси, сетка, подсказки, анимация.
- Калькулятор экономии разъезжался → две колонки маршрутов.
- Таймер на главной без секунд → живые часы.
- На экране поездки кнопки выходили за край, заглушка карты занимала полэкрана без GPS — исправлено.
- Системные `confirm()` заменены шторками подтверждения.

## Проверка

- 28 сквозных проверок в Chrome на размере iPhone 15 (шторки, быстрое добавление за два действия, автодополнение, день календаря, фильтры, подсказка графика, настройки, подтверждения, перезагрузка посреди поездки).
- Скриншоты всех экранов на трёх размерах: `node app/tests/e2e/screens.mjs`.

## Оставшиеся ограничения
- Фоновый GPS и геозоны недоступны сайтам в Safari (см. README).
- Тактильный отклик на iPhone есть только в iOS 18+ и не во всех режимах; Vibration API Safari не поддерживает.
- Карта и поиск адреса требуют интернета (тайлы OpenStreetMap не кэшируются офлайн).
- Проверка выполнена в Chrome с эмуляцией iPhone; финальный взгляд на реальном iPhone в Safari остаётся за вами — особенно размер текста при увеличенном системном шрифте.
- Интерфейс только на русском; строки собраны в `format.js` и экранах — для перевода их нужно вынести в словарь.
